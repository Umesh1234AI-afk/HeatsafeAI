# 🔥 HeatSafe AI

## 🌍 AI-Powered Climate Health Assistant

HeatSafe AI is an AI-powered climate health application developed using Python and Streamlit. It provides real-time weather information, heat alerts, disease risk analysis, and voice guidance for locations around the world.

## ✨ Key Features

-  Search any Country, State, District or City
-  Real-Time Temperature
-  Live Humidity
-  Next Day Temperature Forecast
-  AI Voice Response
-  Heat Alert when temperature exceeds **45°C**
-  Heat-related Disease Risk Information
-  Health Safety Recommendations
-  Supports locations worldwide

> **Note:** Currently, village and small rural locations are not fully supported.
